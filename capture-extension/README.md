# Consumer Capture

A Chrome/Edge Manifest V3 helper with `activeTab` and `scripting` permissions. It runs only when opened on your active page. It sends no network requests, stores no credentials and has no background worker.

1. Unzip this folder. In Chrome, open Extensions, enable Developer mode and choose **Load unpacked**. Select this folder.
2. In the consumer app, select the full answer text. Open Consumer Capture from your extensions menu.
3. Paste the exact question, confirm the consumer surface, and inspect the answer and visible links. Google AI Mode and AI Overviews must be distinguished manually.
4. Download the JSON. In Brand Research, choose **Collect & monitor → Consumer observation → Import a browser capture**.
5. Review the fields and supply the actual location, model, mode, memory and conversation context. Attach a screenshot after saving.

Selection may omit citations that live in a separate source panel. Copy those visible URLs separately. Browser selection and edits are researcher controlled. A capture is not independent authentication and does not establish which sources actually influenced the answer. If the browser blocks injection or the application does not expose selectable text, use the manual observation form.

This is a locally installed research helper, not a Chrome Web Store release. Do not submit it to a store without completing the relevant release and privacy review.
